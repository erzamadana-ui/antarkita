- Setelan [ASUMSI]: `dispatch_enabled` true, `dispatch_offer_seconds` 25, `dispatch_offer_rounds` 6, `dispatch_offer_radius_step_km` 1 (radius ronde r = min(pickup_radius_km layanan, r×step)), `dispatch_accept_no_move_minutes` 5, `dispatch_no_move_min_progress_m` 300, `dispatch_priority_penalty_m_per_s` 20 (urutan kandidat = jarak + delay_s rating × penalti), `dispatch_no_move_suspend_count` 3 (flag accept_no_move ke-3 dalam 7 hari → tangguhkan otomatis via fraud_flag), `dispatch_offer_on_create` false (true = ronde 1 dibuat seketika di create_order tanpa menunggu cron). - Tabel `order_offers` (id, order_id, driver_id, round int (0 = diterima lewat siaran tanpa penawaran), offered_at, expires_at, status 'offered'|'accepted'|'declined'|'expired'|'cancelled', responded_at, **reason** ('taken'|'driver_cancel'|'order_cancelled'|'accept_no_move'|alasan tolak), **distance_m**, **accept_dist_m**; unique (order_id, driver_id)); RLS: driver sendiri atau admin `orders_view`.
- `dispatch_tick(p_now timestamptz default now())` (service_role; cron `antarkita_dispatch` '10 seconds') → `{at, expired, released, offered, broadcast, waiting, other, release_items[]}`: expire → `dispatch_release_stale(p_now)` → `dispatch_offer_next(order, p_now)` untuk order `searching` tanpa penawaran aktif, ronde terpakai < rounds, bukan AntarNow dalam masa tahan.
